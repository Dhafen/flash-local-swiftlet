# Slashplayed 1.5.1 med WolkaraForever

Öppna uppdateringen med din befintliga Slashplayed Companion 1.5.1 på Windows.

1. Packa upp den yttre ZIP-filen. Lämna `slashplayed-wolkara-device-kit.zip` som ZIP.
2. Anslut och lås upp din iPhone. Apple Devices ska känna igen den och utvecklarläge ska vara aktiverat.
3. Öppna PowerShell i Companion-mappen. Skriv `./slashplayed-cli.exe --kit ` och dra den inre ZIP-filen till fönstret för att fylla i sökvägen. Tryck Enter.
4. Uppgradera med samma Apple-ID, signeringsteam och bundle-ID, inklusive samma `--bundle-id` om du valde ett eget. Behåll den gamla appen installerad under uppgraderingen.
5. Öppna Slashplayed och starta den befintliga Forever-installationen.

Det kompletta Windows-paketet innehåller både **Slashplayed Companion.exe** och **slashplayed-cli.exe**. För USB-uppgradering med kommandoradsverktyget, kör `./slashplayed-cli.exe devices`. Vid Apples HTTP 503 under standardinloggningen kan du prova samma kit med `--server-client-info`, vilket använts för den tidigare enhetsinstallationen.

Wolkaras gränssnitt är förvalt på iPhone för Forever och visas på engelska. Du får större gränssnitt, spellhjul, chatt, menyer, karaktärsramar och uppdragskort. Standardlayouten har bara två av Wolkaras klicköppnade hjul (Wheel och Wheel 2). Right Spells och Left Spells börjar på 0. Vid uppgradering fylls lediga platser i hjulen med tidigare sparade sidospells utan att skriva över befintliga val; originalen finns kvar i de dolda sidospellhjulen. Du kan själv slå på sidospellhjul igen i Mobile UI. Slashplayeds extra knappar (Esc, Jump, UI, Edit, kamerahastighet och Reset) är dolda som standard i Forever. Tangentbordet ligger under chatten. Tryck kort för att skriva, eller håll inne tangentbordsknappen för en meny med Escape, Jump, Rotation (F12), byte av touchläge och möjlighet att visa en separat hoppknapp eller återställa alla extra reglage. En liten rund F12-knapp visas på höger sida. Tryck för ett vanligt F12-tangenttryck, eller dra för att flytta knappen (positionen sparas). Tangentbordets långtrycksmeny kan dölja knappen eller återställa positionen. Chatten använder nu F11 internt, inte F12. I spelläget: kort tryck och släpp ger vänsterklick; håll fingret stilla i minst 0,45 sekunder och släpp för högerklick (t.ex. NPC, kistor, föremål). Dra på vänster sida för rörelse, höger sida för kamera, och på gränssnittet för vanliga vänsterdragar. Ett drag ska inte samtidigt ge ett klick. F12 fungerar som tidigare. För att hoppa medan du springer, välj Show / hide Jump button i menyn.

WoW sparar de tidigare spellplatserna i sina befintliga inställningar. Det tidigare MobileCombat-paketet återställer dess menyer om du installerar det igen med samma appidentitet.

Tactara 0.19.0 ingår som ett separat, oförändrat GPL-addon. Befintlig installation skrivs inte över. Aktivera Tactara i AddOns och välj rotation i dess inställningar. Kör `/tac keydown off` utanför strid för att matcha hjulets klick vid släpp; `/tac hide` döljer Tactaras paneler. I Wolkara öppnar du Mobile UI → Customize, trycker på önskad plats i hjulet och väljer Actions → One Button Rotation, AoE Rotation eller Interrupt. Du kan välja flera platser; inga befintliga spells skrivs över automatiskt. Ett tryck skickar ett manuellt klick via spelets secure action-knapp. Rekommenderat: använd den runda F12-knappen i stället för direktklick i hjulet. Kör `/tac keydown auto`, sedan `/tac bind main` utanför strid och tryck på F12-knappen om den inte redan är bunden till huvudrotationen. Ingen chattöppning ska längre konkurrera med F12. Ingen automatisk repetition. Direktklick och svep i strid måste verifieras på fysisk iPhone.

## AI-knappen och rörelsediagnostik

Tryck på **AI OFF** för att starta och på **AI ON** för att stoppa. Texten under knappen visar aktuell status. När **OBS ONLY** visas körs skrivskyddad observation och du styr själv med touchkontrollerna och F12. Håll inne tangentbordsknappen för att nå **AI diagnostics**.

- **En rörelsepuls.** Stå stilla på plan, fri mark och välj **Test AI movement (forward)** under **AI diagnostics**. TEST ACCEPT betyder att inputlagret tog emot pulsen. TEST CLOSER betyder att samma mål blev mätbart närmare, TEST MOVED att spelaren förflyttades utan mätbart målavstånd och TEST NO GAIN att spelaren förflyttades utan bekräftat närmande. TEST STALL betyder att positionen stod stilla under mätfönstret. TEST NO DATA betyder otillräcklig telemetri. TEST INPUT betyder att inputlagret avvisade pulsen.
- **Begränsat närmande.** Auktorisera först den godkända testmiljön enligt nästa punkt. Rikta karaktären själv mot en vald, stillastående fientlig NPC på fri mark. Välj **Test approach (authorized realm, face selected target)**. Diagnostiken skickar högst tre framåtpulser och fortsätter bara efter mätbart närmande till samma mål. Den kräver aktuell, verifierad hälsa på minst 35 procent och väntar vid saknad data, strid, uteblivet framsteg eller när avståndet är högst åtta yards. Touch avbryter. Testet använder ingen modellinferens.
- **Autonomt test.** Välj **AI diagnostics → Authorized test session → Authorize farming in this test session** i en miljö med uttryckligt tillstånd. Tryck sedan **AI OFF** för att starta testloopen. Touch eller fysiskt tangentbord släpper styrningen direkt och visar **AI OFF** med status **AI PAUSED**. Släpp de manuella kontrollerna och tryck **AI OFF** igen för att återuppta loopen. Bakgrundsläge eller sex sekunder utan färsk speldata återkallar testauktoriseringen. **HP BLOCKED** betyder att verifierad spelarhälsa saknas och agenten väntar utan att styra. Appen kan läsa tre bildrader av den synliga hälsomätaren för diagnostik när dess placering är känd. Vid värmenivån SERIOUS gör den högst ett sådant prov var fjärde sekund.
- **Aktiv styrning.** SEARCH provar verifierad Tab. ENGAGE provar Tactara F12. APPROACH följer ett synligt valt mål med korta pulser. IN COMBAT, LOOT CHECK och RECOVER följer offentlig spelstatus. NAV POSITION, MOVE BIND, NAV BLOCK, NO DAMAGE och LOOT UNCONF visar varför loopen håller position eller väntar. INPUT BLOCK visas efter tre avvisade kommandon i följd. Vid kritiskt värmeläge visas AI HEAT och sessionen stoppas.
- **Grind-rutt.** Spela in sträckan i den godkända testmiljön när agenten är avstängd. Öppna **Grind route** och välj **Mark straight route leg** vid start. Dra den flytande joysticken rakt fram 4–12 yards på fri mark och välj samma menyval vid slutpunkten. Börja nästa sträcka inom två yards från den föregående slutpunkten. Profilen finns kvar under den aktuella spelinstansen och rymmer högst åtta sträckor. Om fyra Tab-försök utan valt mål misslyckas följer agenten rutten och söker igen vid nästa vägpunkt. Agenten kan ansluta längre fram när den observerade positionen och riktningen entydigt matchar en verifierad del. Med verifierade vänster- och högerpilbindningar kan agenten svänga vid nästa sträckas start. **TURN BIND** betyder att pilen för den behövda vridningen saknar verifierad bindning. Vid **FACE ROUTE** behöver du rikta karaktären själv. **ROUTE HOLD**, **ROUTE DATA** och **ROUTE BLOCK** visar stoppvillkoret.
- **Bindningar.** Tab måste vara bundet till närmaste fiende och F12 till Tactaras huvudrotation. W måste betyda framåt. För sidsteg krävs Q/A respektive E/D bundna till strafe. För loot krävs Interact With Target på F eller F10.
- **Modeller.** Valet **Observe local models** under **AI diagnostics** kan läsa installerade Laya- eller Pixel2Play-paket lokalt. MODEL FILE och MODEL ERROR gäller diagnostik. Paket placeras under Slashplayeds dokumentmapp som SPModels/Laya respektive SPModels/Pixel2Play. Direktläget använder regelmotorn och behöver inga modellpaket.
- **Synlig hälsa.** Slå på **Health** under **Menu → Mobile UI** och stäng panelen. Välj **Observe visible player health** för att starta skrivskyddad diagnostik på Wolkaras gröna hälsomätare. En uppskattning visas som **HP≈**. **HP WAIT** betyder att nästa prov väntas och **HP NO VIEW** betyder att utsnittet saknas eller är oläsbart. Om WoW visar sin vanliga spelarram och status är **HP NO VIEW**, kontrollera att Wolkaras **Health** är på. Skyddad addon-hälsa blockerar fortsatt autonom styrning tills en tillförlitlig alternativ mätning har verifierats på telefonen.

Kontrollera SHA-256 för den inre ZIP-filen med Get-FileHash och värdet i SHA256SUMS.txt. Kör slashplayed-cli.exe devices om telefonen saknas. Se AI_DEVICE_VALIDATION.md i leveransen för testordning och loggar.
